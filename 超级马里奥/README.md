# 风屿奇旅 · Windy Trails

为手机触屏制作的原创横版平台冒险。狐狸冒险家、绘本场景、八座岛屿、多点触控手柄、弹药射击、背景音乐和即时音效全部随游戏提供。

## 启动

本游戏是原生 HTML / CSS / JavaScript，无 npm 依赖，无构建步骤。JavaScript 使用 ES Modules，需通过 HTTP 打开，不能直接双击 `index.html`。

在当前游戏文件夹运行：

```sh
cd 超级马里奥
python3 -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080`。手机连接与电脑相同的 Wi-Fi，访问 `http://电脑的局域网IP:8080`。macOS 可使用 `ipconfig getifaddr en0` 查看 Wi-Fi IP；若网络接口不同，请从系统设置 → Wi-Fi → 详细信息查看。系统询问时允许服务器接收本地网络连接。

也可将整个游戏文件夹部署到任意静态网页托管服务，手机直接打开网址。横屏视野更开阔，竖屏也可完整操作；横竖屏切换保留游戏状态。iPhone 若不支持网页全屏，可通过 Safari 分享菜单添加到主屏幕。

## 操作与规则

| 操作 | 手机 | 键盘 |
| --- | --- | --- |
| 左右移动 | 左侧 ← / → | ← / → 或 A / D |
| 跳跃 | ↑ 或右侧「跳跃」 | ↑ / W / 空格 |
| 小跳 / 高跳 | 短按 / 长按跳跃 | 短按 / 长按跳跃键 |
| 下蹲 / 快速下落 | ↓ | ↓ / S |
| 冲刺 | 右侧 ⚡ | Shift |
| 射击 / 连发 | 右侧「射击」，点按 / 长按 | J 或 F，点按 / 长按 |
| 暂停 / 继续 | 右上暂停 / 弹窗继续 | Esc / P |

- 支持多根手指同时操作，可以同时移动、跳跃和射击，也可配合冲刺；方向键按住后可滑向另一个方向。
- 从上方踩蘑菇怪获得 2 枚金币；侧面碰撞损失 1 颗心，短暂无敌。
- 从下面顶 `?` 宝箱，获得 3 枚金币、叶子护盾或弹药补给。护盾抵挡一次怪物或尖刺伤害，不能保护坠落。
- 默认简单模式，每关 3 颗心；困难模式每关 2 颗心。坠落或计时耗尽损失 1 颗心并在最近旗帜处复活，生命归零可重试，重试保留所选模式。
- 每关隐藏 3 颗星光；星光是可选的探索目标，抵达终点石门即可进入下一关。
- 旗帜激活本关复活点，弹跳蘑菇可以帮助登高；后续关卡有上下移动的平台。
- 冲刺持续 0.19 秒，冷却 1.2 秒；冲刺不提供碰撞无敌。
- 暂停、切换标签页或移出窗口会清空输入并暂停游戏，避免误操作。
- 背景音乐和音效在主动点击开始后启用；右上声音按钮可静音。
- 本地保存声音偏好，以及简单 / 困难模式各自的关卡完成情况、金币和星光纪录。进行中的关卡进度保留在当前页面内，刷新页面会从起点开始。

## 文件与隔离

```text
超级马里奥/
├── index.html       # 独立页面与触屏手柄
├── style.css        # 横竖屏、刘海安全区与界面
├── game.js          # 游戏循环、物理、交互、状态与结算
├── levels.js        # 八关配置、双模式差异与色彩主题
├── art.js           # 原创矢量绘图、角色动画与素材缓存
├── audio.js         # Web Audio 合成音乐与音效
├── combat.js        # 射击参数与子弹连续碰撞检测
├── save.js          # 本地存档校验与旧纪录兼容
├── assets/icon.svg  # 原创狐狸图标
├── package.json     # 仅声明模块类型与测试命令，没有依赖
├── tests/           # 关卡数据测试与浏览器通关回归
└── README.md
```

所有路径均为相对路径，整个目录可独立移动或部署。没有修改上层项目配置，没有全局依赖、Service Worker、外部字体、CDN、埋点或下载的美术素材。存储键为 `windy-trails:v1`，与其他游戏隔离。所有 JS 模块默认不创建全局变量；仅在 URL 添加 `?debug` 时暴露 `window.__windy` 供本地检查。

## 性能与实现

- Canvas 2D 绘制；狐狸的 12 张动画帧、树木、灌木、地面及方块预绘制到离屏画布并缓存，避免每帧重复创建复杂图形。
- 固定 60 Hz 物理更新，单帧最多补偿 3 次更新；渲染使用 `requestAnimationFrame`，限制画布像素比为 2。
- 只绘制可见场景物体；屏幕附近的敌人才更新；粒子上限 110 个，浮动文字上限 12 个。
- HUD 数值变化时才更新 DOM。页面隐藏时不绘制，暂停 Web Audio；遵循减少动态效果的系统设置。
- Pointer Events 和 pointer capture 支持多点触控；处理 pointer cancel、按键释放、窗口失焦等情况。
- 音效由振荡器合成，结束后释放音频节点。运行时没有资源下载和网络请求。

## 两种模式

每次打开或刷新页面默认选中「简单模式」。首页点击模式按钮后再出发；同一段旅途的下一关、复活和重试都沿用当前模式。回首页可切换模式。

| 项目 | 简单模式 | 困难模式 |
| --- | --- | --- |
| 每关生命 | 3 颗心 | 2 颗心 |
| 前三关 | 保留原始路线、敌人速度和计时 | 增加敌人、尖刺与更宽沟壑 |
| 敌人速度 | 基础速度 | 基础速度的 1.5 倍 |
| 沟壑 | 关卡标准宽度 | 第一关 +20、第二关 +25，其余 +40 逻辑像素 |
| 时间 | 180～280 秒 | 简单模式的 70% |
| 星光浮台 | 宽 128 | 宽 104 |
| 浮桥 | 宽 104 | 宽 80，横移速度更快 |
| 坍塌平台 | 踩上后 1.1 秒坍塌 | 踩上后 0.55 秒坍塌 |

两种模式的跳跃高度、普通移动速度和冲刺操作一致。坍塌平台在消失 4 秒后恢复；站在移动平台上会随平台移动。困难模式会为加宽后的沟壑保留落地空间，旗帜和复活点均放在安全地面。

## 子弹道具与射击

- 每关开局附近与复活旗帜附近各有一包金色弹药；部分 `?` 宝箱也提供补给。两种模式的八关均可获得。
- 简单模式每份补给 12 发，困难模式 8 发，最多携带 30 发；满弹药时不会消耗地面弹药包或弹药宝箱，部分补充最多加到上限。
- 手机按右侧上方的「射击」按钮，键盘按 J / F；轻点单发，按住约每 0.25 秒发射一次。可以同时移动、跳跃和射击。顶栏及射击键角标显示剩余弹药。
- 子弹沿角色当前朝向水平飞行，每发消耗 1 发弹药。击败一只怪物获得 2 枚金币，同一只怪物不会重复给奖励。
- 子弹会被地面、砖块和有效浮台挡住，不能清除尖刺；子弹不穿透敌人，空中射击要注意高度。
- 坠落复活保留剩余弹药，并清除场上旧子弹；重新挑战本关、选择关卡或进入下一关时弹药归零，补给重新生成。暂停会冻结子弹并释放按键。
- 子弹采用连续碰撞检测，避免高速移动穿墙；同屏逻辑最多存在 6 发子弹，每发最多存在 0.95 秒，到期自动清理。枪口闪光、命中粒子、弹药拾取及发射音效均沿用本地绘制与合成方案。

## 验证记录（2026-10-10 更新）

- 48 项单元测试全部通过：21 项关卡数据、16 项子弹碰撞 / 补给、6 项存档校验、5 项音频异常处理。
- 浏览器回归包含 27 项机制 / 记录检查、8 项异常环境 / 真实触摸事件检查，以及 16 条实际物理通关路线，均通过。通关路线只发送移动、跳跃、冲刺按键并推进固定时间步，不修改生命、传送角色或跳过碰撞。
- 检查坍塌与恢复、平台载人、冰面减速、尖刺 / 护盾、困难模式重试、两种模式的最终结算与独立完成记录。
- 使用移动端浏览器触摸事件验证三指移动 + 跳跃 + 射击与松手清理，检查地图选关和第三关后能继续进入第四关。
- 检查 320×568、375×667、390×844、430×932、844×390、1280×800 六种视口，模式按钮与控制键均可见，地图最后一关可通过滚动访问。
- 保留对实体手机的验证边界：浏览器模拟不等同于 iOS Safari、微信内置浏览器或低端手机的实际触感与持续帧率。

在本游戏目录运行数据测试，无需安装依赖（使用支持 ES Modules 和内置测试器的 Node.js）：

```sh
node --test tests/*.test.mjs
```

`tests/browser-checks.mjs` 导出 `verify(page, baseURL)`，可接入已有 Playwright 环境。建议使用独立浏览器上下文，以免测试纪录写入实际游玩的本地存储。`tests/environment-browser-checks.mjs` 导出 `verifyEnvironment(page, baseURL)`，用于异常存档、存储不可用、音频不可用和触摸取消的浏览器验证。游戏运行不加载测试文件。

### 本轮边界问题修复

- 触摸被浏览器取消或失去捕获后，清除尚未执行的射击、冲刺与跳跃；正常快速点按继续保留输入缓冲。
- 复活等待期间已经按下又松开的动作不再延迟到复活后执行。
- 方向键滑回中心或滑出方向区时释放该触点的方向输入，重新滑入仍可继续操作；其他触点或键盘输入独立保留。
- 子弹生成时补查从角色手部到枪口的路径，修复贴身敌人漏判及枪口跨过近距离薄障碍的问题。
- 本地存档先校验结构与数值范围，避免异常星数、损坏 JSON 或错误字段使地图 / 结算报错；有效纪录及旧版成绩予以保留。
- 音频 API 缺失、初始化失败或恢复播放被拒绝时，游戏可继续无声运行，失败的音频初始化会释放已创建的资源。

这些检查覆盖当前可复现的问题，不代表对所有浏览器和实体手机环境作出无缺陷保证。
