# 准星、人物血条与主动战斗改进（2026-10-11）

## 准星与镜头

参考经典射击游戏的细线十字样式，改为绿色四线、中空中心和深色描边。准星始终在屏幕正中心，与实际瞄准射线一致。走动和开火时线间距略微变大，肩后瞄准时收拢。

普通第三人称镜头后移到约 5.7 个世界单位，目标高度提高，肩侧偏移增大，让自己的角色处于更靠左下的位置，空出中央射击视野。横竖屏会调整肩侧偏移，避免竖屏时把角色挤出画面；画幅比例通过受限输入传递给服务器，客户端与服务器使用相同的镜头计算。

依然保留小眼睛 / Alt 自由观察、肩后瞄准和镜头避墙。准星与枪口的两次射线检测继续使用，因此镜头能看见、枪口被墙挡住时不会隔墙命中。

## 人物头顶血条

- 自己、队友、敌人都有血条与剩余数值。
- 同队绿色，敌队红色，低血量变为橙色；返场保护时显示金色描边。
- 受击、回血、阵亡、返场都读取真实对局血量；联机读取服务器快照。
- 血条保持可读的屏幕尺寸，不随距离无限缩小。遮挡检查使用角色身体位置，防止通过墙看见血条。
- 仅在血量整数、队友关系或保护状态变化时重绘血条纹理，避免每一帧重绘所有 Canvas。

## 人机为什么原来不怎么打真人

原来的目标筛选偏向最近的可见敌人，容易长期和人机队友交火。简单难度的额外散布为 0.15 弧度，发射间隔也较长；枪口在角色侧方，而原先瞄准方向从角色中心计算，进一步降低命中率。

本次改为：

1. 优先追击存活的敌方真人，不会一直被远处机器人之间的交火吸引。
2. 记录实际攻击来源，受到真人或近距离敌人攻击时可以还击。
3. 子弹从实际枪口指向目标身体，再叠加对应难度与武器的散布。仍逐发进行墙体和角色碰撞检测。
4. 加入有限转身速度和反应时间，不允许朝向背后时立即开火。
5. 使用短连射与停顿；简单保留更大的散布、较慢射速与较低伤害，困难反应更快、瞄准更稳。
6. 按武器选择交战距离，困难人机安全侧移，太近时后撤。追击途中不再一直保持减速瞄准。
7. 保留反向最短路共享缓存、完整身体通行检测和绕障路线。路点移动量按实际武器移动速度限制，避免高速冲锋枪越过路点。

## 验证与边界

固定初始随机种子 1、7、19、42、73，三张地图各模拟五次 45 秒对局。每局是真人静止不射击、2 位简单人机队友、4 位敌人。敌方随机武器，以下比较的是**简单难度是否实际命中真人**：

| 地图 | 修改前命中真人的对局 | 修改后 | 修改后首次受击时间 |
| --- | ---: | ---: | ---: |
| 积木乐园 | 2/5 | 5/5 | 2.02～11.88 秒 |
| 海港仓库 | 3/5 | 5/5 | 2.02～10.50 秒 |
| 沙漠遗迹 | 3/5 | 5/5 | 2.02～8.33 秒 |

修改前 15 组中有 7 组在整整 45 秒内没有命中真人；修改后 15 组都命中。统计记录位于 `test/artifacts/ai-pressure-before.json` 和 `ai-pressure-after.json`。这些是受控、静止玩家的测试，不代表移动玩家每局都会在固定时间受击。

已加入 7 项战斗回归，基础测试总计 38 项。覆盖真人优先级、受击还击、两种难度四种枪实际命中、反应时间、墙体与保护期、三地图固定种子压力，以及横竖屏准星与弹道对齐。

`test/browser-combat.cjs` 使用真实 WebSocket 服务与手机触摸输入，检查：

- 敌人真实射击后，真人 HUD 和头顶血条同时减少。
- 真人通过触屏拖动瞄准、按住开火后，敌人真实血量和血条同步减少。
- 队友 / 敌人血条颜色、准星居中和角色与准星的间隔。
- 横竖屏切换、死亡隐藏血条、返场恢复以及墙后血条不可见。

可运行：

```bash
npm test
node test/ai-pressure.mjs
# 安装 Playwright 并有 Chrome 时，可运行（自动启动临时服务）
node test/browser-combat.cjs
```
