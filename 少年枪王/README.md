# 少年枪王 · Junior Blasters

一个手机优先的 3D 第三人称泡泡射击游戏。三张明亮的主题竞技场、机器人队员、无限弹药，没有血腥画面。重点是开箱即玩的单人冒险、清晰的音效反馈和同一局域网内的双人合作 / 对抗。

这是浏览器游戏：手机无需安装 App。电脑提供页面和局域网房间服务，两部手机访问同一个地址即可游玩。当前不是微信原生小程序安装包。

## 启动

本目录已经安装依赖。macOS 可以双击 **启动游戏.command**，或在终端运行：

```bash
cd /Users/anshunli/gitHub/anGames/少年枪王
npm start
```

换一台电脑时，先安装 Node.js 20 或更新版本，然后在本目录执行：

```bash
npm ci
npm start
```

服务启动后终端会列出地址：

- 电脑：`http://localhost:3000`
- 手机：使用终端显示的 `http://192.168.x.x:3000` 等局域网地址。

两部手机和电脑连接同一 Wi-Fi，打开**同一台电脑的同一个地址**。保持电脑和终端运行。端口被占用时可使用 `PORT=3001 npm start`。服务监听 `0.0.0.0`，允许局域网设备访问；无需 HTTPS 或公网服务器。

不要直接双击 `index.html`：ES 模块和房间连接需要通过上述 HTTP 服务加载。运行时的模型、脚本和音效都来自本机，不使用 CDN，也不下载外部美术或声音资源。

## 单人冒险

1. 在地图预览下方选择地图，再选择「单人冒险」，输入昵称，选择红队或蓝队。
2. 蓝队默认是你 + 2 位简单人机，另一队默认 4 位简单人机。改变真人队伍后，可以通过「配置人机」重新安排两队人数。
3. 选择武器，点击「开始冒险」。点击「随机惊喜」则每次返场随机选择武器。
4. 可设置 2 / 3 / 5 / 10 分钟、10 / 20 / 30 / 50 / 100 分。先达到目标分或时间用尽结束。

泡泡命中减少快乐能量，能量归零时对方得 1 分。3 秒后自动返场，返场后有 2 秒保护。5 秒未被命中开始恢复能量。友军不会受到伤害。单人菜单会暂停对局，切到后台也会暂停。

## 两人联机

1. 两部手机打开同一电脑提供的局域网地址。
2. 两人都选择「好友联机」，输入相同的 4～24 位房间密码。第一位进入的人是房主。
3. 自己选择红队或蓝队。两人同队就是合作，分属红蓝队就是对战。
4. 房主选择地图，并配置两队的人机。访客会同步看到地图选择，不能修改房主的地图。默认从单人模式切换到联机时，同队的人机伙伴由 2 位减为 1 位，这样可以组成「你 + 真人伙伴 + 人机伙伴」。仍可自由增减。
5. 房主点击「全员出发」。只有房主可以修改阵容、开启对局和带全员返回房间。
6. 结算后房主可「再来一局」，或「返回大厅」让双方换队和改阵容。

每个房间最多 2 位真人，机器人另计。相同密码会加入同一房间，不同密码互不干扰。正在对局的房间不接受中途加入。伙伴掉线时会移除其角色；房主离开会自动移交房主身份。联机菜单**不会暂停整个房间**。访客返回大厅会离开房间，之后可在房间回到大厅时重新加入。

## 地图与第三人称视角

大厅预览下方的三个按钮可以切换地图，预览、地图标题和对局会一起更新：

| 地图 | 布局与风格 |
| --- | --- |
| 积木乐园 | 中央高塔、彩色积木掩体和多条绕行路线 |
| 海港仓库 | 长条集装箱、木箱、中央通道，外围有海水、吊机和灯塔 |
| 沙漠遗迹 | 暖色沙地、石墙和石柱，分散的掩体形成交错通道 |

三张地图有独立的障碍物、碰撞和人机寻路数据，小地图显示当前地图的掩体。地图选项随房间配置发送给所有玩家，不同房间可以同时使用不同地图。对局中不能换图；回到大厅后可换图重新开始。

进入游戏后，镜头位于自己角色的后上方，可以看到完整小人、背包和双手持枪。角色靠左下方，中央是清晰的绿色细线十字准星；横竖屏会自动调整肩侧偏移。每个人物都有头顶血条与剩余数值，同队绿色、敌队红色，墙后的敌人不会显示血条。角色行走时双腿摆动，换枪时手中的模型也会切换。右侧滑动 / 鼠标移动会转动镜头及角色朝向。

- 手机：**按住小眼睛并拖动**，可绕角色观察四周和正面；也可以一只手按住眼睛，另一只手滑动空白区域。松手后镜头回到角色身后。
- 电脑：**按住 Alt + 移动鼠标**自由观察，松开 Alt 回到角色身后。
- 自由观察只改变观察方向，不改变角色或正在发射的枪的方向。
- 点击瞄准会拉近到肩后视角，依然能看到持枪角色；狙击枪的放大倍率更高。
- 镜头靠墙时自动收近，避免穿进掩体。准星从镜头确定目标，再从枪口检查弹道，因此即使镜头越过矮墙看到对手，枪口仍被挡住时也不能隔墙命中。

## 自由混编人机

「配置人机」中分别编辑蓝队和红队，每位机器人都可以选择：

- 难度：简单 / 困难。
- 武器：随机 / 泡泡步枪 / 糖果冲锋 / 彩虹散弹 / 星星狙击。

支持例如 **1 困难 + 10 简单**、**1 简单 + 5 困难**；预设按钮可以直接应用这两种组合。也可以逐个增删，或者用「纯双人对决」清空全部人机。两支队伍均至少需要一个真人或人机才可开局。

每队最多 24 位机器人，共 48 位。较多机器人会提高设备负载；低性能手机可以降低数量并选择「流畅」画质。两种难度都会主动追击敌方真人，并在受到攻击后还击。简单人机移动和射击较慢、散布较大、伤害较低；困难人机反应更快、瞄准更稳，会侧移和保持交战距离。双方都有转身与反应时间，短连射之间会停顿，仍需绕开障碍且不能隔墙命中。

## 武器与声音

| 武器 | 特点 |
| --- | --- |
| 泡泡突击步枪 | 射程、精度和射速均衡 |
| 糖果冲锋枪 | 移动快、射速快，远距离散布较大 |
| 彩虹散弹枪 | 一次发射七颗泡泡，适合近距离 |
| 星星狙击枪 | 伤害高、射速慢，开镜放大倍率更高 |

四种枪都有不同的音色和节奏。另有命中提示、得分旋律、脚步、跳跃、受击、返场、胜利和轻音乐。声音通过 Web Audio 实时合成，有限幅压缩和音量控制；附近其他角色的发射声按距离衰减并提供左右声像。

浏览器通常需要点击或触摸后才允许播放声音。点击开始后仍无声时，检查大厅右上角音符、设置中的音量，以及手机系统媒体音量 / 静音设置。自动化验证检查了音频节点触发，实际扬声器听感需要在设备上体验。

## 操作

| 动作 | 手机 | 电脑 |
| --- | --- | --- |
| 移动 | 左摇杆 | WASD / 方向键 |
| 转向瞄准 | 右侧空白区域滑动；开火键上拖动也可瞄准 | 鼠标 |
| 自由观察 | 按住小眼睛并拖动，松开回到身后 | 按住 Alt + 鼠标 |
| 连续开火 | 按住大圆开火键 | 按住鼠标左键 |
| 开镜 | ⊕ 瞄准键，再点取消 | 鼠标右键切换 |
| 跳跃 | ↥ 跳跃键 | 空格 |
| 换枪 | 点击底部当前武器 | Q 循环 / 数字 1～4 |
| 奔跑 | — | Shift + 移动 |
| 菜单 | 左上角暂停按钮 | Esc |

手机推荐横屏，支持移动、瞄准和开火的多指操作。设置中可调整转向灵敏度、手机辅助瞄准、音量、轻音乐、触屏按键和画质。辅助瞄准只在准星已经接近可见对手时轻微吸附，不会隔墙锁定。手机浏览器如果不允许网页自动横屏或全屏，手动横放即可正常玩。

## 验证

基础验证无须额外工具：

```bash

```

另外提供四份 Playwright 浏览器回归脚本（需要安装 Playwright，并有 Chrome）：

```bash
# 可选：仅当需要复跑浏览器验证时安装
npm install --no-save --package-lock=false playwright

# 先在另一个终端运行 npm start
node test/browser-smoke.cjs

# 自行启动临时服务，验证双浏览器联机
```

浏览器回归覆盖桌面及手机尺寸、无横向溢出、混编开局、换枪、开镜、Esc 暂停、两个同时触点的移动与开火、松手停止、音频节点、双人红蓝对战、换地图后同队重开、结算一致及房主转移；还验证三张地图里角色头脚都在画面内、持枪模型随换枪更新、手机小眼睛与电脑 Alt 独立旋转视角及松开复位。截图保存到 `test/artifacts/`。已使用本机 Chrome 的手机模拟环境验证，尚未在两台实体手机 / iOS Safari 上进行实机测试。

## 寻路与优化

人机现在按“地图 + 目标节点”复用反向最短路距离表，目标移动后按节点更新，每张地图最多缓存 64 张表；身体通行检测与射击视线分开，防止卡在矮箱子和墙角。

寻路修复、缓存边界与该轮性能记录见 [NAVIGATION.md](NAVIGATION.md)；2026-10-11 的准星、血条与主动战斗改进见 [COMBAT.md](COMBAT.md)。基准统计的是规则计算时间，不代表手机帧率。

## 文件结构

```text
少年枪王/
├── index.html                 大厅、设置与对局 HUD
├── style.css                  手机 / 桌面布局
├── server.js                  静态服务、密码房间、权威对局与 WebSocket 同步
├── src/
│   ├── navigation.js          按目标共享的最短路距离表、LRU 缓存与地面扫掠
│   ├── maps.js                三张地图的共享布局与主题
│   ├── simulation.js          单人 / 服务器共享规则、第三人称镜头几何、碰撞、命中、AI 寻路
│   ├── renderer.js            Three.js 场景、角色、武器、粒子、小地图
│   ├── controls.js            触屏多指操作、摇杆、鼠标键盘
│   ├── audio.js               本地音效合成与轻音乐
│   └── game.js                大厅、对局状态与网络客户端
├── assets/icon.svg            原创图标
├── test/                      规则、网络、浏览器回归
├── 启动游戏.command            macOS 双击启动
├── REFERENCES.md              参考与依赖说明
└── package.json
```

单人规则在浏览器本地运行；联机规则在电脑服务器运行，客户端只发送操作，由服务器计算碰撞、命中、血量和比分，以 30 Hz 计算、15 Hz 广播。场景用程序化积木模型构建，静态模型按材质合并，减少手机绘制开销。当前有三张竞技场地图、四种武器和第三人称持枪角色；没有账号、付费、聊天、广告或数据上传功能。
