# 少年枪王 · 战术竞技场 2.0

Three.js + 原生 JavaScript 的浏览器射击游戏，支持单人 AI 作战与两人局域网联机。2.0 重做大厅、角色装备、场景材质与灯光，加入据点目标、弹匣管理、方向闪避和双视角。

## 启动

```bash
cd 少年枪王
npm ci
npm start
```

电脑打开终端显示的 `http://localhost:3000`；手机与电脑连接同一 Wi-Fi，使用终端显示的局域网地址。macOS 也可以双击 `启动游戏.command`。需要 Node.js 20+ 与支持 WebGL 的浏览器。

如果 3000 端口已被使用：

```bash
PORT=3001 npm start
```

## 规则与资源

- **轮换据点**：默认模式。进入半径 6 米的区域，约 3 秒完成中立据点占领；控制后每秒 +1。双方都在区域时占领与计分暂停。敌方控制的据点需要先中和，再占领。每 50 秒迁移至地图上的下一处区域。击败敌人额外 +1。
- **团队歼灭**：击败敌人 +1。先到目标分数获胜；时限结束比较比分，相同则平局。
- **150 点生命**：头部命中双倍伤害。3 秒返场、2 秒返场保护；开火或闪避立即解除保护。脱战 5 秒后每秒恢复 18 点生命。
- **弹匣与换弹**：四把枪拥有独立弹匣。R 手动换弹，空弹匣开火自动换弹；换弹期间不能开火。切枪取消当前换弹，已消耗的弹药保留。备用弹药不设上限，返场补满所有弹匣。
- **体力**：冲刺每秒消耗 23，常态每秒恢复 17。方向闪避消耗 28、冷却 2.8 秒，移动约 5.3 米。闪避接受地图碰撞约束，不提供无敌。

## 枪械

| 武器 | 定位 | 单发基础伤害 | 射击间隔 | 弹匣 | 换弹 |
| --- | --- | ---: | ---: | ---: | ---: |
| AR-24 脉冲 | 中距连续压制 | 22 | 0.145 秒 | 30 | 1.65 秒 |
| VX-9 疾风 | 高速突入 | 15 | 0.075 秒 | 36 | 1.35 秒 |
| SG-8 破阵 | 近距爆发，8 枚弹丸 | 16 / 弹丸 | 0.78 秒 | 8 | 2.25 秒 |
| SR-7 长弓 | 远距精确打击 | 86 | 1.15 秒 | 5 | 2.6 秒 |

超过有效距离后伤害逐渐衰减，远距离最多降至基础伤害的 40%。瞄准减小散布；射击产生向上的后坐力，需要手动压枪。狙击瞄准具有单独的光学准星和较小视场。

## 操作

| 操作 | 桌面 | 触屏 |

| 移动 / 转向 | WASD / 鼠标 | 左摇杆 / 右侧滑动 |

| 换弹 / 切枪 | R / Q 或 1–4 | 换弹按钮 / 点当前武器 |

| 跳跃 | 空格 | 跳跃按钮 |
| 第一／第三人称 | V | 视角按钮 |

## 地图、AI 和画质

- **霓虹前哨**：装甲掩体、多路交锋与城市天际线。
- **深蓝港区**：集装箱侧翼、货运吊机、港口水面与暮色灯带。
- **落日遗迹**：石阵掩体、暖色夕照与远近距离博弈。

地图碰撞与遮挡布局来自共享规则，场景在原有布局上重做材质和细节，并加入天空渐变、夕照与装甲倒角。角色、枪械、地表纹理、特效和音效均由本项目生成，没有新增商业模型或贴图。

AI 保留视线、反应时间、转向速度、寻路和受伤撤退。争夺模式中部分队员在无接触时推进据点，其他队员搜索敌方；老兵受击后会尝试方向闪避。阵容可逐个配置标准／老兵及枪械，两队各最多 24 个人机。

均衡／精致画质启用阴影与辉光；流畅模式关闭这两项并限制像素密度。镜头通过共享几何约束避开掩体，准星与枪口分别检测遮挡；贴墙无法利用肩后视角隔墙射击。

## 局域网联机

两位玩家打开同一服务地址，在「好友联机」中输入相同的 4～24 位房间密码。相同队伍合作，不同队伍对抗。房主控制地图、规则、阵容与开始／重赛。服务器以共享规则模拟据点、弹药、换弹、体力、闪避、碰撞和伤害，再向双方发送权威状态。

## 验证

```bash
npm run check
npm test
npm run test:browser
node test/browser-startup.cjs
```

浏览器验证默认使用本机 Chrome；可通过 `BROWSER_CHANNEL` 指定其他已安装的 Chromium 通道。Playwright 为开发依赖，不参与运行时页面加载。

`test/browser-startup.cjs` 检查桌面与手机的开局和再次开局，覆盖音频正常、授权始终未响应、被拒绝、不可用及初始化失败。比赛启动不会等待音频授权完成。`test/tactical.test.js` 覆盖新规则，`test/browser-tactical.cjs` 覆盖三张地图、真实命中、换弹、闪避、视角、暂停、手机多指输入及双客户端权威同步。报告和截图写入 `test/artifacts/`。`test/VALIDATION.md` 记录本次验证结果与范围。

## 主要文件

- `src/simulation.js`：单人 / 服务器共享战斗、资源、据点、AI、瞄准与镜头规则。
- `src/renderer.js`：场景、角色、材质、灯光、后期、粒子与小地图。
- `src/controls.js`：鼠标键盘、触屏、多指操作与动作缓冲。
- `src/game.js`：大厅、对局 HUD、音效事件和网络客户端。
- `src/navigation.js`：共享最短路距离表、LRU 缓存与地面扫掠。
- `server.js`：静态资源、房间、WebSocket 权威模拟。

战斗细节见 `COMBAT.md`；寻路说明见 `NAVIGATION.md`；依赖与参考见 `REFERENCES.md`。
