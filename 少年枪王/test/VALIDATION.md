## 本轮修复

- 修正头盔非等比缩放、大厅侧栏溢出及手机按键遮挡弹药卡片。
- 据点导航与敌人目标分离，避免将区域坐标当作角色产生无效俯仰或虚构射击。
- 为快速换弹／闪避按下增加 180 毫秒输入缓冲；暂停和失焦清空动作。
- 点光源特效到期释放时兼容没有几何和材质的对象。
- 使用当前 Three.js 支持的阴影类型；后期管线按帧累计渲染统计。
- 腿部／躯干／头盔分区命中，胸口命中不再自动视为爆头；地面截断向下弹道。
- 旧测试显式指定对应地图／规则；将非法掩体内的战斗测试坐标移到可行走区域，反击测试固定散布以单独验证反击行为。

## 2026-10-11 · 开始游戏阻塞修复

检查发现开始按钮会 `await audio.unlock()`；当浏览器的音频恢复 Promise 一直不完成时，比赛创建、画面切换和输入启用都不会执行。本机正常音频环境未复现用户的具体卡住场景，因此本次补充了故障注入以验证这一阻塞路径。

- 开始比赛不等待音频授权；声音可用时再加入，音频不可用不会阻止作战。
- 部分初始化失败的音频上下文清理后置空，避免后续返场／射击音效访问未初始化对象。
- 开始按钮在渲染器准备好后才启用；重复点击不重复创建已经开始的比赛。
- `npm run check` 通过，`npm test` 仍为 **50 / 50**。
- `node test/browser-startup.cjs` 通过：桌面和手机分别覆盖正常音频、恢复始终未响应、恢复被拒绝、音频 API 不可用、构造失败、部分初始化失败，共十二种情况；每种均检查首次开局、返回大厅及再次开局。未捕获异常及 console error 为零。
- `node test/browser-tactical.cjs` 通过：三地图、射击命中、换弹、闪避、视角、暂停、手机横竖屏／多指输入和真实双客户端联机回归。

移动端为 Chrome 触控与视口模拟，未在用户实际手机上复现其原始问题。
