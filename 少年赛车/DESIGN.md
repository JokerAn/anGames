# 少年赛车 3.1 · 手动竞速

## 玩家承诺与设计简报

玩家靠自己读弯、刹车、转向和出弯加速争取名次，而不是跟着赛道看一段车辆动画。主操作是油门 / 制动 / 转向；次操作是受控漂移、出弯加速、道具攻防、主动氮气、倒车、带代价的救车、三种视角切换。每 5～30 秒读取弯道方向与建议速度，在弯前减速、修正线路、出弯加速；每 1～3 分钟完成两圈并看到圈数、干净圈、罚时和有效总成绩。长按油门不转向必然冲出赛道；静止空输入不启程，转向松开只回正前轮，不会把车头吸回中心。熟练玩家通过更短刹车、更低滑移、干净检查点和尾流超越取得优势。

默认排位竞速：六车、两圈、有序八检查点，碰撞和越界真实损失时间；连续越界超过 0.5 秒部分按 2 秒/秒罚时，干净圈才能进入最快圈。仅按 R 救车回最后合法检查点，加 3 秒并使当前圈不计干净圈。普通比赛脏圈若依次通过所有检查点仍计完成圈，漏点或路外过线不计圈。时间挑战独自驾驶，对总时间争夺金银铜牌与同配置个人最佳，全部圈必须干净才有有效挑战成绩；道具竞速保留加速带、箱体、三档漂移蓄能和攻防道具。每个弯道在保留抓地与主动侧滑之间选择，蓄能成功后松开漂移得到真实出弯加速；道具提示明确是否有目标，使用时机影响排名。默认竞速和时间挑战不摆自动加速带，Shift 氮气必须主动使用。

不将画面特效当作驾驶规则；保持现有 Three.js / 原生 JS / Web Audio / Node / WebSocket，固定 60Hz，自定义车辆与碰撞。世界位置和车头由轮胎抓地限制下的纵向 / 侧向速度、转角、角速度独立积分；路面投影只供距离、边界、碰撞和判门。不是独立四轮悬挂模拟，不引入新引擎或在线美术服务。

## 核心循环与代码契约

玩家踩油门并主动转弯，通过检查点完成规定圈数，同时抓地极限、出界、六车交通与计时造成风险；好走线获得出弯速度、干净检查点补氮气和尾流加速，失误造成物理减速、罚时和最快圈无效，撞停后可倒车修正或付费重置。道具赛中，受控侧滑到达蓝／金／紫焰后松开漂移换取加速与氮气；越界、碰撞、低速或制动使蓄能作废，直线乱按不能获奖。

- `controls.js` 只生成明确的手动意图；移除旧自动油门，即使旧 localStorage 或属性仍写着 true 也不会产生油门。R 为递增输入序号，保证短按跨渲染和网络不丢失；失焦 / 菜单为停车意图，不会自动倒车。
- `driving.js` 唯一负责世界物理与赛道投影。人类路径不得调用 `driverInput`（只供 AI），不自动纠正 heading / x；重置是唯一显式改变位置并受规则代价约束的玩家操作。
- `race-rules.js` 对八个检查点顺序、完整圈、干净圈、罚时、逆行、重置与实际帧内过线时间记账；不积分车头或回中。时间挑战成绩区分干净圈，不允许切弯 / 瞬移到终点获胜。
- `drift.js` 只读取车辆侧滑并维护蓄能／奖励，`items.js` 负责确定性补给、瞄准与攻防，均不写转向或世界位姿。
- `simulation.js` 固定更新顺序：读取意图 / 重置 → 资源 → 世界运动 / 护栏 → 补给 / 道具（仅arcade）→ 车体碰撞 → 检查点 / 圈 / 有效总成绩 → 排名。单人与服务器运行同一规则。
- `course-guidance.js` / `race-hud.js` 只提示前弯、速度、检查点和违法原因，不产生方向 / 油门。`renderer.js`、`presentation.js`、`effects.js` 和 `audio.js` 只读取权威状态。

## 赛道 / 关卡计划

沿用三条闭环，但将它们作为驾驶挑战，而非自动滚动画面：起跑后几秒遇到第一弯，必须真实转向；看清外侧刹车牌与弯方向提示，入弯可短刹车，出弯逐渐给油。320 米直线提供放松、主动氮气和超车机会，随后读弯制动。检查点门跨整条道路，未过门以前不计该段。赛车驶出 9 米半路宽先进入草地 / 路肩失去抓地与速度；护栏在 ±13.5 米提供恢复余地，不能沿护栏自动拐弯。

海岸：较宽容的节奏和长直线，新手先学会第一弯、检查点与出弯；山岭：坡度、连续曲率与更密集制动；夜环：用路灯 / 门架和边线保持方向读图。下一弯约 10～155 米预告，建议速度与橙 / 绿线路提示都由真实曲率算出。保持可见危险到失误之间的反应空间，不在加速出口塞无预警路障。

## 可观察验收

1. 新旧设置下空输入不移动、不通过检查点；按住油门不转向不能完成一圈，三地图分别验证。
2. 不限于模拟：真实浏览器键盘 / CDP多指输入验证转向、刹车、倒车、罚时重置，且重置短按只执行一次。
3. 完整两圈时间挑战必须靠真实操作走完所有门，显示有效成绩 / 奖牌 / 个人最佳；漏点、反向过线、路外过线和瞬移负控不能完赛。
4. 三地图 AI 在同物理下可以完赛；双浏览器权威同步操控与重置，断线停车不倒车或取消比赛。
5. 横竖屏提示和油门 / 刹车 / 重置按钮不遮挡，暂停 / 重赛 / 音频 / 图形恢复仍可靠。

## 3.1 继续打磨

弯前提示以完整弯段的收紧位置作为目标，根据车速、车型和坡度估算制动距离，只在需要时提示立即制动；仪表与路面提示共享计算。必须避免入口较缓而内弯急收时显示过快的入弯建议。

时间挑战通过个人最佳幽灵提供可以主动追赶的具体目标。幽灵是本人实际有效记录的被动回放，不算 AI 对手、不计碰撞和排名，不写入人类输入。一个轨迹最多10Hz、300秒、固定样本与字符串上限，本地存储不可用不阻塞比赛。完整干净、零罚时的更快成绩才能覆盖。实时对比采用相同进度的首次到达时间；起步／中途停等允许，真实倒车导致多义时不显示差值。

失败恢复必须能靠手动倒车脱离草地，不能由于固定草地阻力大于倒车驱动力而在零速处正负振荡。高速度时仍保留草地阻力，低速度时渐进介入。


## 道具、漂移与镜头迭代 · 2026-10-17

**驾驶决策。** 沿用现有三条赛道与固定 60Hz 自定义车辆模型；后轴抓地渐进进入与退出侧滑，刹车优先于手刹。有效漂移必须主动按键、车速至少14m/s、保持转向与真实侧滑，且在路面内、朝向可控。允许利用惯性侧滑；短暂0.18秒修正保留蓄能，持续恢复抓地或反向摆车不积累奖励。

| 漂移阶段 | 有效侧滑累计 | 松开漂移的奖励 |
| --- | --- | --- |
| 蓝焰 | 0.55秒 | 0.75秒出弯加速、10点氮气 |
| 金焰 | 1.15秒 | 1.20秒出弯加速、16点氮气 |
| 紫焰 | 1.90秒 | 1.80秒出弯加速、22点氮气 |

蓄能最多2.4秒；仪表、后轮火花与松键事件使用同一档位。出弯加速拥有单独计时，不缩短道具氮气或加速带；制动、复位、碰撞与冲出路面取消漂移奖励。

**攻防循环。** 第一个箱体可由实际油门／转向拾取，既有长直线作为稳定教学与奖励释放区。氮气适合直线，油污铺在身后6米、持续18秒、车主免疫；脉冲需要连续进度前方65米、横向4.5米以内且位于车头±30°，不能隔圈或穿过回头弯击中。无目标保留道具并提示。护盾清除减速并保护6秒，命中反馈保留来源与攻击者。后半名次的确定性补给适度增加追赶道具，所有排名仍能取得四类道具；每车油污最多4处、全场最多32处。AI 在起步8秒后按车位错峰决策，直线用氮气、有追车时丢油、有效瞄准才发脉冲，受减速或危险时开盾；实际成功使用后间隔至少12秒，和玩家共享同一激活与命中规则。

**空间与可见性。** 跟车用于读线、引擎盖沿真实朝向驾驶、广角用于观察相邻车手与出弯空间；侧滑时兼顾速度方向和车头。倒车、复位和远距离位移及时切换或复位，避免穿车／飞越赛道。窄竖屏静态增加相机距离、高度和视场；手机横屏的道具说明与踏板保留独立空间。减少动态效果偏好关闭震动、侧滚与FOV冲击，保留简短静态提示。


## 电玩城夜赛迭代 · 2026-10-17

**设计简报。** 玩家承诺是用更直接的左右转向，在霓虹灯海中读弯、漂移、超车。主操作仍为手动油门、刹车和转向；转向轮锁及轮胎侧向能力同时上调，不能只改车轮模型。每5～30秒在普通出弯、火箭直线冲刺和瞄准冰冻之间选择，每场两圈读懂新赛道节奏、争夺含罚时总成绩。高水平玩家在灯光引导下提前读弯，留出空间使用火箭，并通过护盾、车道与使用距离处理冰冻威胁。失误仍会撞墙、减速与丢失干净圈；可以倒车或付3秒复位，快速重试。不加入自动转向和四轮独立悬挂。

**核心循环。** 玩家主动转向与刹车通过检查点，在弯道与交通压力下取得道具，选择直线用2.2秒火箭或瞄准前车发2.4秒冰冻来争夺位置；成功获得真实速度或对手时间损失，失误造成冲出道路、碰撞、罚时与奖励作废。普通氮气为续航补给，火箭为更强短冲刺；脉冲为65米群体减速，冰冻为85米最近单体强减速，护盾可解冻。六类道具都有明确预览和有效事件，转向始终可用。

**赛道与灯光计划。** 新增「霓虹游乐场」：不对称技术弯、低坡度、两条320米恢复直线，起跑约45米的首箱固定火箭，第二箱固定冰冻，在到达连续加速带以前学习取舍。弯外LED、护栏外灯塔、跨路拱门和色彩分区给出方向与地标；门架净高至少6米，不在盲弯或加速出口用装饰遮挡车道。既有都市夜环也获得灯光秀。路侧追逐灯条、扫描光束与灯光地标缓慢变化，不做全屏频闪；减少动态效果时保留静态彩灯。高低画质按实例数量、光束与少量无阴影局部照明降档，重赛必须释放私有资源。



## Premium 画质迭代 · 2026-10-18

**设计简报。** 玩家承诺不变（手动油门/制动/转向，读弯、走线、争名次）。本轮只提升观看与反馈层：暮光到霓虹的统一光照脚本、低角度暖光与分层大气透视、克制的 bloom 与夜间湿路反射；四主题各有独立轮廓语言（海岸棕榈/海崖/海岛灯塔，山岭层理台地/岩柱/砂岩拱门，都市窗格高楼/霓虹广告/天际线，游乐场帐篷/门柱/漂浮环/灯串）。所有美术程序化生成，不引入外部图片、模型、字体或在线生成服务。

**渲染契约。** `renderer.js` 仍是唯一渲染入口，只读取权威比赛状态；`postfx.js`（HDR+bloom+调色）、`sky-environment.js`（天空/PMREM）、`surface-textures.js`（缓存纹理库）、`track-scenery.js`（分层世界 kit）均为纯表现模块，THREE 由调用方注入、无 vendor import，可被 Node 测试加载。后处理仅在 post>0 时启用，档位由实际帧时间自适应升降；低档保留直出路径。资源回收：切场/重赛释放世界几何与私有材质，天空云纹理与 kit 纹理为跨场缓存；上下文恢复后重建后处理与 PMREM 并重新上传缓存纹理。

**性能与取舍。** 高清档 bloom 链 +5 draws / +6 textures；世界 kit 高清档 30–39 draws、≤59k tri，低画质自动减量并隐藏 detailGroup；车辆合批、车轮/刹车灯/贴花不再投射阴影，检查点与弯道牌改为共享 atlas 合并绘制，相较初版集成显著降低了 draw calls。移动端 active-play draw calls 约 150–230，高于 technical-art 的 150 starting point，按「6 辆完整车型 + 分层世界 + 后处理」记录为 tradeoff；首次进入主题的一次性着色器编译停顿（本机 headless 实测 1.8–6.5s）为已知未优化项，同主题重赛无开销。

**验收。** 画面证据：`test/artifacts/premium/desktop-race-*.png`、`mobile-race-arcade.png`、`desktop/mobile-garage.png` 与 before 基线；指标：本项目 canvas inspector 的 colorEntropy 5.3–6.8、edgeDensity 0.22–0.37、contrast 162–216（GPU: ANGLE Metal）。玩法回归：全部既有 Node/浏览器专项通过，详见 `test/VALIDATION.md` 与 `artifacts/final-evidence.md`。
