# 少年赛车

面向手机浏览器的 3D 街机赛车。内置车型／引擎选择、三个闭环赛道、六车同场、碰撞反馈、漂移与道具，以及局域网双人房间。

## 启动与手机游玩

需要 Node.js 20 或以上版本。首次安装与启动：

```sh
cd 少年赛车
npm install
npm start
```

macOS 也可以双击本目录的 `启动游戏.command`。服务默认监听所有网卡的 **3210** 端口，终端会打印本机和局域网地址。

1. 电脑保持游戏服务运行。
2. 手机和电脑连接同一 Wi-Fi，手机浏览器打开终端打印的 `http://电脑局域网IP:3210`。**手机上不要输入 localhost**。
3. 推荐横屏。竖屏也能操作，车库页面可上下滚动。浏览器打开后无需外部 CDN 或图片服务。
4. 单人点击「出发，上赛道」；双人都选「好友开黑」，填写昵称和**相同的 4–8 位数字房间号**。第一位进入的玩家为房主。
5. 两人都点「我准备好了」，房主点「发车」。每人可选不同车型和引擎；赛道、圈数和人机难度以房主进入房间时的选择为准。

如果地址打不开，检查是否在同一网络、电脑防火墙是否允许 Node.js 的入站连接、路由器是否开启访客网络／AP 隔离。电脑有多个网卡时，选与手机同网段的地址。**只输入同一房间号不足以跨电脑服务互联**，两部手机必须访问同一个服务地址。

更改端口：`PORT=3211 npm start`。不能双击 `index.html` 直接玩；页面使用 ES modules，联机也需要服务。

## 操作

| 动作 | 手机虚拟按键 | 键盘 |
| --- | --- | --- |
| 转向 | 按住左／右箭头 | ← / → 或 A / D |
| 油门 | 默认自动；关闭自动后按住「油门」 | ↑ 或 W |
| 刹车 | 按住「刹车」 | ↓ 或 S |
| 漂移 | 同时按住方向键与「漂移」，松开释放蓄能 | 空格 + 方向键 |
| 氮气 | 按住「氮气」 | Shift |
| 道具 | 点击已拾取的道具 | E |
| 菜单 | 右上角暂停按钮 | Esc |

支持多指同时转向、漂移和氮气。手指移出按钮后松开、触摸取消、切换应用均会清理按键，避免卡键。单人切换应用时暂停；联机不会暂停，切换应用时打开比赛菜单并自动刹车；返回后点击继续比赛。短暂失去网络输入的车辆也会自动刹车。音效默认关闭，在车库点「音效」开启。

## 完整规则

- 每局 6 辆车：单人 + 5 AI 或双人 + 4 AI；选择 2 圈或 3 圈。
- 倒计时结束后起跑，完成全部圈数，按实际冲线顺序排名；显示排名、圈数、计时、最快单圈、速度、氮气与小地图。
- 第一辆车冲线后，其余车辆有 35 秒完赛；整场比赛上限 300 秒。未完成显示 DNF。
- 路线为封闭赛道。车辆沿赛道前进，玩家控制横向转向、刹车和漂移，是容易上手的街机操控；没有倒车、驶出赛道探索或拟真四轮悬挂模拟。
- 转向漂移持续超过 0.65 秒，松开后获得氮气和短暂加速。松开氮气键后会缓慢自然恢复，持续使用会消耗储量；耗尽后按住不会继续加速。
- 车身碰撞会横向推挤并损失速度；护栏、路障会减速。重装车型质量更大、更耐撞。碰撞包含车身偏移、火花、画面震动、合成音效，支持的手机可短震动。
- 绿色箭头为加速带，驶过获得 1.7 秒加速。金色贴地礼盒为道具箱，车身接触即可拾取，高速经过也会连续检测。一次携带一个道具；道具槽已满时提示先使用已有道具。拾取后礼盒在该玩家的画面中消失，3 秒后恢复；每辆车独立判定，不影响另一玩家拾取。
- 超级氮气：3 秒加速并补充氮气。
- 减速油污：在身后留下持续 18 秒的陷阱，车辆驶入后减速／打滑 2.4 秒。
- 减速脉冲：命中前方 65 米内、无护盾的车辆，减速 3.5 秒。
- 防撞护盾：持续 6 秒，抵挡碰撞速度损失、油污与脉冲，仍有车身物理分离。
- AI 会选择线路、避障、漂移、使用氮气与道具；「轻松兜风」适合入门。

### 车辆与引擎

| 车型 | 特点 |
| --- | --- |
| 流星 GT | 均衡跑车，适合初次游玩 |
| 闪电 R | 轻量方程式，起步与操控好，但碰撞吃亏 |
| 泰坦 X | 重装越野，耐撞推力强，极速和起步略慢 |

| 引擎 | 相对基础参数 |
| --- | --- |
| 街道 V6 | 均衡 |
| 涡轮 V8 | 极速 +12%，加速 -17%，氮气消耗更快 |
| 电驱 E | 加速 +25%，极速 -4%，氮气持续时间 +25% |

三条赛道分别是 **晴空海岸、赤岩峡谷、霓虹都市**，路线曲率、长度、起伏与场景不同。所有配置直接开放，不含付费／账号系统。

## 技术与目录

- `server.js`：Node HTTP 静态服务、WebSocket 房间、60Hz 服务端比赛计算、20Hz 状态广播。
- `src/simulation.js`：单人和服务端共用的物理／比赛规则，输入清洗、人机、圈数、排名、碰撞、道具。
- `src/tracks.js`：车辆与引擎参数、按弧长采样的封闭路线、赛道对象。
- `src/renderer.js`：Three.js 真 3D 场景、车辆、车库、跟车镜头、实例化风景与粒子。
- `src/controls.js`、`src/audio.js`：多指虚拟按键、键盘、Web Audio 合成音效。
- `src/game.js`、`index.html`、`style.css`：车库、房间、比赛 HUD、结算与移动端布局。
- `test/`：规则、全赛道人机完赛与真实 WebSocket 集成测试。

客户端只发送操作输入，双人比赛的位置、圈数、碰撞与道具由服务端决定。渲染插值用于平滑网络画面。断线玩家由 AI 接管，离开后可重新创建房间；**目前不支持中途加入或断线恢复同一辆车**。房主离开会移交给剩余玩家；比赛结束后房主可返回房间重新准备。

画面采用低多边形程序化模型，限制像素比，路面批量几何、树木／建筑使用实例化渲染。要求 WebGL 2；真实手机表现取决于 GPU、浏览器和网络。浏览器模拟验证不能代替真实 iPhone／Android 的触控、音频、发热与帧率测试。

## 验证

```sh
npm run check
npm test
```

测试包含倒计时、输入过滤、加速／刹车、碰撞、漂移、道具与护盾、完赛结算、三条赛道 AI 全程、房间隔离与权限、满员、断线接管和静态文件边界。

浏览器截图保存在 `test/artifacts/`，用于查看车库与手机比赛布局。

可选的浏览器回归脚本为 `test/browser-audit.cjs`。需要可用的 Playwright 与 Chrome，并先启动游戏服务：

```sh
node test/browser-audit.cjs
```

如果 Playwright 安装在其他位置，可以设置 `PLAYWRIGHT_MODULE` 指向该包目录；`RACER_URL` 可指定测试服务地址（默认 `http://localhost:3210`）。脚本检查旧连接回调隔离、加入房间超时、后台刹车、菜单与结算切换、真实双客户端拾取和短按道具，以及三赛道车辆朝向。结果见 `test/VALIDATION.md`。
