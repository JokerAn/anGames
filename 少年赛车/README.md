# 少年赛车 3.1 · 手动竞速

Three.js 三维赛车，沿用原生 JavaScript、Web Audio、Node / WebSocket。以实际油门、制动、转向、检查点和冲线成绩构成比赛，支持四赛道、三车型 / 动力、单人及局域网双人。

**3.0 完全关闭自动油门。** 旧版本保存的自动油门也不会启用。玩家车辆不调用 AI 控制，不会自动沿赛道转向、回到中心或用护栏带着过弯。无人操作保持静止；只踩油门不转向会驶离赛道。页面左上角显示 `3.1 · 手动竞速`，新旧版本请通过版本标识区分。

## 启动

需要 Node.js 20+ 和支持 WebGL 2 的浏览器。

```sh
cd 少年赛车
npm ci
npm start
```

电脑打开 `http://localhost:3210`；手机连同一 Wi-Fi，打开服务打印的电脑 IP 地址。macOS 可双击 `启动游戏.command`。改端口用 `PORT=3211 npm start`。开发和联机必须通过 HTTP 访问，不能直接打开 HTML。

已有旧页面时刷新一次；服务启动时已加载规则模块，修改规则后需重启 Node。车辆、程序纹理、场景和合成声音都本地生成，没有外部 CDN、美术下载或录音依赖。

## 开一场能自己掌控的比赛

1. 车库选择车型、动力、赛道、规则和难度。默认赛道竞速、两圈。
2. 倒计时后按住油门起步；看前弯提示和路面箭头，在弯前刹车，转向过弯，出弯再加速。
3. 依次通过 8 个检查点并回到起点才完成一圈。门架高亮下一检查点，HUD 显示检查点、完成圈、干净圈状态和罚时。
4. 过快入弯会推头；驶离路面会降低抓地和速度。撞停时可倒车自行调整，或按 R 返回最后合法检查点，付出 3 秒罚时。
5. 冲线后看到原始用时、罚时和总成绩。时间挑战还会显示奖牌与同配置个人最佳；可以立即重跑。

## 三种规则

| 规则 | 目标 | 车辆与辅助 | 有效性与奖励 |
| --- | --- | --- | --- |
| 赛道竞速 | 六车争夺含罚时总成绩 | 单人 + 五辆 AI，或双人 + 四辆 AI；手动油门 / 转向 / 氮气；无自动加速带和道具 | 有序检查点决定完成圈；脏圈仍可完成比赛，但不记最快圈；干净检查点补少量氮气，尾流提供短时超车机会 |
| 时间挑战 | 完成两圈或三圈，争夺奖牌与个人最佳 | 单人独跑；双人联机时各自计时；无 AI、无车体互撞、无自动加速带和道具 | 所需圈都干净才是有效挑战成绩；金银铜目标由赛道长度 / 圈数计算，按赛道、圈数、车型、动力和难度分别保存最佳 |
| 道具竞速 | 六车竞速并利用道具争夺名次 | 手动驾驶；保留加速带、补给箱、油污、路障、漂移资源奖励与主动氮气 | 仍需有序检查点，罚时计总成绩；三档漂移松键后提供出弯加速与氮气 |

越界连续前 **0.5 秒**不累计罚时，超出部分按 **2 秒 / 秒**累计；越界本身立即让当前圈不计干净最快圈。碰撞、重置也使当前圈失去干净圈资格。漏检查点、倒车过线和路外过线不能制造完成圈。重置会付出 3 秒并保留已赚取的检查点，必须补完后面的门；没有重置直接漏门需要重走一圈。时间挑战未达到完整干净圈的成绩不进个人最佳，普通竞速则保留真实完成圈与罚时结果。

排名根据完赛车手的 `原始时间 + 罚时`，未完赛车手按合法进度排序。首车完赛后其他车最多继续 35 秒；比赛总时限根据路线 / 圈数设定，未完成显示 DNF。倒计时不能抢跑。

## 操作

| 动作 | 手机 | 键盘 |
| --- | --- | --- |
| 油门 | 按住右侧「油门」 | W / ↑ |
| 转向 | 左侧连续摇杆 | A / D 或 ← / → |
| 制动 / 倒车 | 按住「刹车」；停车后继续按约半秒进入倒车 | S / ↓ |
| 手刹漂移 | 转向时按住「漂移」，蓄能后松开 | 空格 + 方向，松开空格出弯 |
| 主动氮气 | 按住「加速」 | Shift |
| 复位救车 | 点击「复位」 | R |
| 道具 | 道具模式点击已拾道具 | E |
| 跟车 / 引擎盖 / 广角 | 顶部视角按钮 | C |
| 菜单 | 顶部暂停 | Esc |

制动优先于油门、氮气和手刹；手刹渐进降低后轴抓地，松开时逐渐恢复，保留真实滑移。松开方向只回正前轮，车头保留实际朝向。若长按氮气耗尽，必须松开才恢复，不会免费反复触发；干净的非起点检查点可补 5 点氮气。

摇杆支持连续力度，手机支持多指同时油门 / 转向 / 制动。触摸取消、失焦和后台清空动作。菜单 / 网络超时使用停车输入，不会无人倒车；单人暂停模拟，联机菜单不暂停其他玩家。复位使用递增序号，短按跨帧 / 网络不丢失，也不会因为重复快照执行多次。

## 道具与漂移出弯

道具竞速中，保持有效侧滑 **0.55 / 1.15 / 1.90秒**，分别点亮蓝焰、金焰、紫焰；**松开漂移**可获得 **0.75 / 1.20 / 1.80秒**加速，并补充 **10 / 16 / 22点**氮气。独立能量条提示当前档位与释放时机，后轮火花随档位变化。按键但没有侧滑不蓄能；草地、碰撞、制动、低速失控或复位会取消。惯性滑行时也可主动漂移，短暂修正允许继续蓄能。

| 道具 | 使用时机与效果 |
| --- | --- |
| 超级氮气 | 直线释放，至少3秒加速并补20点氮气 |
| 火箭冲刺 | 独立2.2秒强加速，极速上限提高到基础的1.44倍；适合直线，刹车优先 |
| 冰冻弹 | 瞄准85米内最近一辆有效前车，使其强减速2.4秒；可被护盾抵挡与解除 |
| 减速油污 | 在身后6米铺设，持续18秒，车主免疫；每车最多4处 |
| 减速脉冲 | 瞄准前方65米、横向4.5米与车头±30°内的对手；无有效目标会保留道具 |
| 防撞护盾 | 立即清除减速与冰冻，开启6秒保护，可抵挡脉冲、冰冻弹、油污和碰撞 |

小地图下方显示道具效果与目标数量，按 **E** 或点击道具使用；目标进入范围时脉冲按钮会强调提示。补给可复现，后半名次适度增加追赶道具，仍需自行走线和使用。AI 也会按路况、追车和威胁选择释放时机，起步至少8秒后才使用，并有12秒以上间隔。赛道竞速与时间挑战保留手刹物理，采用各自的驾驶奖励。

## 驾驶模型与赛道

车头 `heading`、世界位置 `worldX/worldZ`、纵向与侧向速度独立积分。车轮转角、车速、横向抓地上限、制动、坡度与草地共同决定实际轨迹，松开控制不会跟随赛道切线。赛道投影仅测量连续进度和横向偏移、执行道路 / 护栏接触与检查点判定。人类输入路径不调用 AI 驾驶器；AI 使用相同运动 / 碰撞规则，通过自己的转向与提前制动过弯，卡住 / 漏点时支付同样的复位罚时。

路面半宽 9 米；外侧先是有速度和抓地损失的路肩，护栏约在 ±13.5 米，留有自行收车空间。碰撞产生真实侧向速度冲量和质量相关分离。六挡自动变速箱带迟滞，电驱单挡，倒车显示 R。仍属于受抓地约束的简化竞速物理，不是独立四轮悬挂仿真。

| 车辆 | 特点 |
| --- | --- |
| 赤曜 GT | 中置双门跑车，均衡调校 |
| 银箭 R | 开放座舱，轻量、加速和抓地更强 |
| 曜夜 GTS | 长轴距 GT，更重、耐撞，起步较慢 |

海岸公路适合学习走线，山岭隘口有坡度和连续技术弯，都市夜环用灯光与护栏表达方向；新增霓虹游乐场，有专属火箭／冰冻补给、光环门架、彩色追逐灯带和扫描光束。四条赛道都有 320 米直线和连续技术路段；默认模式用直线主动氮气和超车，道具模式则有三个间隔 70 米的加速带，每次接触持续 3.7 秒。加速前后保留安全距离，不把无提示障碍放在加速出口。前弯提示与路面箭头只给建议，不代替转向或制动。

## 弯前制动与个人最佳幽灵

3.1 的弯道预告会查找完整同向弯段中的收紧位置，根据车型抓地、当前车速、距离和坡度给出建议。仪表区分“约多少米后减速”“准备减速”和“现在刹车”，路面箭头使用同一制动估算。建议不会操作油门、刹车或方向；不同走线的可用抓地仍可能变化，需要玩家判断。

时间挑战完整干净、零罚时完赛后，会保存本人的最佳幽灵轨迹。下一场同赛道、圈数、车型、动力和难度时，半透明幽灵按最佳成绩的实际时间回放，并显示到达相同进度时领先／落后多少秒。幽灵不在赛车名单内，不碰撞、不占名次、不发声，也不会控制玩家。靠近本人时隐藏模型，减少遮挡；可通过“幽灵 开／关”按钮切换模型，仍保留时间差对比。

轨迹只存本浏览器，按实际模拟／权威状态最多 10Hz 采样，最长 300 秒、有样本和 JSON 大小上限。倒计时、不完整记录、脏圈、罚时和慢于最佳的成绩不会覆盖最佳轨迹；存储不可用时比赛继续、内存内仍可回放。起步停车不会破坏时间差比较，真实倒车或非单调回放不计算含糊的进度差。保存轨迹失败不会阻止正常成绩与个人最佳的记录。

草地低速阻力也已调整：长按刹车能稳定倒车脱困，不再在零速处反复跳挡；路肩仍会损失速度与抓地。

## 音效、镜头与特效

音效默认关闭，在车库或比赛菜单开启，偏好会保存。V6 / 涡轮 V8 根据转速与油门生成不同点火脉冲、谐波和负载；电驱为独立电机层，静止不发电机声。还有换挡卸载、涡轮泄压、风噪、滚动、滑胎、路肩和碰撞混音。近处最多两辆对手有距离衰减、左右声像与相对速度音高变化。暂停、返回车库、停止驾驶时淡出连续声，音频授权挂起不会阻塞比赛或按钮。

车身与车轮分离表现，加减速俯仰、转弯侧倾、路肩小幅起伏通过阻尼弹簧回稳；刹车灯逐车独立。按 C 在跟车、引擎盖和广角之间切换，选择会保存。跟车综合世界位姿、车头与速度方向，侧滑时兼顾车身和前弯；广角提供更多周边空间，窄竖屏自动增加可视道路范围。倒车按实际行进方向观察，复位与远距离位移即时清除旧镜头运动。程序车漆 / 玻璃 / 沥青材质与三主题户外反射建立层次，高清档夜赛前灯实际照亮路面。

胎烟源于后轮接地点，透明扩散消退，滑移与制动留下短时胎痕；碰撞火花优先于烟雾；分档漂移火花、拾取、脉冲扩散与护盾命中使用同一预算，不在每次事件新建模型。对象池、实例化面片、固定种子、数量与寿命上限避免无限累积。减少动态效果偏好关闭额外胎烟 / 火花、镜头震动、加速视场冲击和速度线，保留短时道具提示。

## 局域网双人

双方访问同一个电脑服务地址，选择「双人联机」，输入昵称及相同的 4～8 位数字房间号。双方准备后房主发车，路线 / 圈数 / 难度 / 规则以房主为准。排位与道具模式补齐至六车，双人时间挑战各自计时、无 AI。真实位置、资源、检查点、罚时和救车均由服务器权威计算。断线转 AI 接管；超过 900 毫秒没有输入则停车。

无法连接时检查同一 Wi-Fi、防火墙及访客网络 / AP 隔离。手机 `localhost` 指手机自身，须用服务打印的电脑 IP。

## 自动画质

画质只改变绘制预算，不改变驾驶规则与 60Hz 模拟。硬件提示选择启动档位，实际慢帧降档、持续稳定后升档；后台和首次编译不纳入测量。

| 档位 | 渲染目标 | DPR上限 | 像素预算 | 阴影 / 额外细节 |
| --- | --- | --- | --- | --- |
| 流畅 | 30fps | 0.72 | 65万 | 关闭 |
| 均衡 | 60fps | 1.0 | 125万 | 关闭 |
| 高清 | 60fps | 1.5 | 240万 | 开启 / 1024阴影 |
| 精细 | 60fps | 2.0 | 360万 | 开启 / 2048阴影 |

粒子各档最多 18 / 36 / 64 / 96，胎痕最多192段；车身按材质合并，场景实例化，远车隐藏。目标预算不等于实体手机的帧率、发热或续航保证。`window.__racerDebug` 只读查看版本、手动输入、世界位置、检查点、罚时、音效状态和画质资源。

## Premium 画质升级 · 2026-10-18

在不改变驾驶规则、物理、联机与输入路径的前提下，渲染层完成了一轮 premium 画质升级，仍然是全程序化美术、无外部 CDN / 美术下载 / 录音依赖，也没有新增运行时依赖。

- **HDR 后处理（`src/postfx.js`）**：场景渲染到 HalfFloat/MSAA target，经 bright-pass 与 4~5 级 mip bloom 后，由单次合成 pass 完成 ACES 色调映射、曝光、对比 / 饱和 / 色温、暗角、颗粒、径向色差和随速度增强的径向模糊。`post` 档位 0=直出、1=仅调色、2=bloom；高清档 bloom 链只增加 5 个 draw、6 张纹理。
- **程序化天空与环境（`src/sky-environment.js`）**：四主题天空（日间低太阳暖光 + 云层 / 夜间月亮、星空、城市辉光）以及程序化 equirect → PMREM 户外反射；天空每场 3 draw calls。
- **分层世界 kit（`src/track-scenery.js` + `src/surface-textures.js`）**：近 / 中 / 远三层 + 起终点看台、赞助商 / 里程 / 警示牌、轮胎墙、灯塔、风旗、维修区与四主题专属道具；共享 32 张程序化纹理与合并 / 实例化批次，高清档 30–39 draws。
- **车辆与路面**：清漆车漆、碳纤纹理、玻璃、镀铬排气、轮圈 / 刹车细节、灯组、涂装贴花、前铲 / 侧裙 / 扩散器 / 尾翼端板与接地阴影；可平铺的沥青 albedo / normal / roughness、路缘、砂石路肩、轮胎磨损带、反光标柱与升级后的起终点门架。
- **画质档位**：流畅 / 均衡 / 高清 / 精细 分别使用直出 / 仅调色 / bloom+2xMSAA+4mips / bloom+4xMSAA+5mips；自适应降档仍按实际帧时间工作。移动端高配档也会开启轻量 bloom。
- **验证**：新增 `npm run test:premium`（postfx / scenery / 运行时审计）与 `npm run inspect:canvas`（项目内 canvas inspector，输出像素与渲染预算报告）；证据与前后对照见 `artifacts/final-evidence.md`、`artifacts/evidence.json`，过程记录见 `artifacts/game-progress.md`。

收尾修复：速度线特效的 reduced-motion 参数曾被取反导致高速时不显示、窄竖屏车库文案与展台重叠、速度线视觉过强；已修复并加入 `test/premium-runtime-audit.cjs` 回归（速度线可见性、6 种视口 HUD、重赛资源、证据钩子隔离）。

已知限制：首次进入某个主题时会有一次性的着色器编译准备（现在通过隐藏画布在发车前预热：本机 headless 点击开始约 10.5 秒，之后倒计时以 60fps 顺畅进行；真机通常更快但未实测）；同一主题重赛无此开销。移动端 active-play draw calls 约 150–230，高于 technical-art 的 150 starting point，属于「6 辆完整车型 + 分层 kit + 后处理」的已记录 tradeoff；headless 的 FPS 不作为真机帧率证据。

- `src/driving.js`：世界运动、空间投影、抓地限制、倒车、侧向冲量与 AI 驾驶。

## 更直接的转向与电玩城夜赛

左右车轮转角和车辆横向抓地一起调整，低中速响应更直接，高速仍保留有限抓地、刹车优先和松方向不自动回赛道的规则。相同0.4秒、65%方向输入的世界车头对照中，6～55m/s范围转角增加约63%～92%；键盘和手机摇杆走同一物理路径。

在车库选择「霓虹游乐场」体验第四条路线，选择「道具竞速」体验六类道具。第一处彩色箱固定给火箭冲刺，第二处固定给冰冻弹；其他箱按可复现的补给序列发放。赛道竞速与时间挑战也能选择新路线，依照各自规则驾驶。

都市夜环与霓虹游乐场都有道路灯光秀：RGB光环、追逐灯带、LED立面、光塔、扫描光束与彩色地面光池。实体构件放在护栏外，跨路构件保持净高；质量分档降低灯光密度与光束数量，减少动态效果时保留静态彩灯。
