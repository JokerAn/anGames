# 验证记录

验证环境：本机 Node.js 24.21.0；独立 Chrome 无头浏览器，真实 WebGL 渲染；390×844 竖屏与 844×390 横屏、触控事件模拟。

已通过：

- JavaScript 文件语法检查。
- 14 项 Node 自动化测试：三赛道全程、车辆／道具／碰撞、输入清洗、房间隔离、房主权限、满员、断线接管、权限移交与再战。
- 1440×1000 桌面车库和比赛画面；390×844 手机车库无横向溢出。
- 关闭自动油门后，倒计时结束仍保持静止；触摸油门后正常加速。
- 通过 Chrome DevTools 的真实触控事件，同时按住油门、右转和漂移；三个输入均生效，松手后全部清除。
- 单人暂停后比赛计时停止。
- 两个独立浏览器上下文从房间 UI 加入同号房间，使用泰坦 X 与闪电 R，各自准备并由房主发车。
- 两客户端使用相同赛道，均可加速，采样时比赛时间相差 0.05 秒；车辆数据匹配（允许网络广播间隔内的运动误差）。
- 关闭一位玩家的浏览器上下文，另一端看到其车辆由 AI 接管。
- 实时跑完两圈单人比赛，玩家用时 36.80 秒；等待全部车辆结算后出现六行成绩，点击再来一局重新进入倒计时。
- 霓虹赛道的手机竖屏画面正常显示。
- 以上浏览器流程没有 console error 或未捕获异常。

截图在本目录的 `artifacts/` 中。测试只能证明本机浏览器及服务逻辑，不代表已在真实 iPhone／Android 上测量帧率、耗电、震动、音频或跨 Wi-Fi 网络条件。

## 全代码复查与修复回归

本轮修复：

- 道具短点击用递增序号传递，跨过渲染／网络采样间隔仍执行；重复状态不会重复使用。
- 冲线时间和单圈时间采用帧内越线时刻，近距离同时冲线按先后排名。
- 空氮气按住不再间歇触发免费加速；加速带不再缩短现有更长的加速效果。
- 车辆车头朝向与横移方向一致，起跑时立即采用赛道朝向。
- 旧 WebSocket 回调不能污染新比赛；切换模式取消正在加入的房间；加入确认也纳入超时。
- 联机切到后台关闭油门并刹车，返回后由菜单继续；回房间和结算断线正确关闭／保留对应弹窗。
- 护盾连续碰撞有反馈冷却，避免每帧刷屏。
- 异常昵称与输入使用安全默认值，避免创建空房间后无法清理。
- 圈数、难度正确保存和恢复。

验证结果：

- `npm run check` 通过。
- `npm test`：31 项全部通过，包含原有三赛道 AI 全程与此前左右方向／道具修复相关覆盖。
- `test/browser-audit.cjs` 通过：手机尺寸浏览器的旧连接隔离、暂停、连接超时、短点击、后台刹车、再战与断线弹窗均符合预期。
- 两个真实独立浏览器客户端在临时测试服务 3211 端口进入同一房间，成功拾取道具、在同一 JavaScript 任务内按下并松开 E 释放道具，以及掉线 AI 接管。
- 三赛道实测 3D 车头方向与左右横移一致；浏览器无未捕获异常。

仍未覆盖真实 iPhone／Android 的浏览器兼容性、触感、发热和长期帧率；不将本轮测试视为“绝对没有任何 bug”的保证。
