# 验证记录

验证环境：本机 Node.js 24.21.0；独立 Chrome 无头浏览器，真实 WebGL 渲染；390×844 竖屏与 844×390 横屏、触控事件模拟。

已通过：

- JavaScript 文件语法检查。
- 14 项 Node 自动化测试：三赛道全程、车辆／道具／碰撞、输入清洗、房间隔离、房主权限、满员、断线接管、权限移交与再战。
- 1440×1000 桌面车库和比赛画面；390×844 手机车库无横向溢出。
- 关闭自动油门后，倒计时结束仍保持静止；触摸油门后正常加速。
- 通过 Chrome DevTools 的真实触控事件，同时按住油门、右转和漂移；三个输入均生效，松手后全部清除。
- 单人暂停后比赛计时停止。
- 两个独立浏览器上下文从房间 UI 加入同号房间，使用泰坦 X 与闪电 R，各自准备并由房主发车。
- 两客户端使用相同赛道，均可加速，采样时比赛时间相差 0.05 秒；车辆数据匹配（允许网络广播间隔内的运动误差）。
- 关闭一位玩家的浏览器上下文，另一端看到其车辆由 AI 接管。
- 实时跑完两圈单人比赛，玩家用时 36.80 秒；等待全部车辆结算后出现六行成绩，点击再来一局重新进入倒计时。
- 霓虹赛道的手机竖屏画面正常显示。
- 以上浏览器流程没有 console error 或未捕获异常。

## 全代码复查与修复回归

本轮修复：

- 道具短点击用递增序号传递，跨过渲染／网络采样间隔仍执行；重复状态不会重复使用。
- 冲线时间和单圈时间采用帧内越线时刻，近距离同时冲线按先后排名。
- 空氮气按住不再间歇触发免费加速；加速带不再缩短现有更长的加速效果。
- 车辆车头朝向与横移方向一致，起跑时立即采用赛道朝向。
- 旧 WebSocket 回调不能污染新比赛；切换模式取消正在加入的房间；加入确认也纳入超时。
- 联机切到后台关闭油门并刹车，返回后由菜单继续；回房间和结算断线正确关闭／保留对应弹窗。
- 护盾连续碰撞有反馈冷却，避免每帧刷屏。
- 异常昵称与输入使用安全默认值，避免创建空房间后无法清理。
- 圈数、难度正确保存和恢复。

验证结果：

- `npm run check` 通过。
- `npm test`：31 项全部通过，包含原有三赛道 AI 全程与此前左右方向／道具修复相关覆盖。
- `test/browser-audit.cjs` 通过：手机尺寸浏览器的旧连接隔离、暂停、连接超时、短点击、后台刹车、再战与断线弹窗均符合预期。
- 两个真实独立浏览器客户端在临时测试服务 3211 端口进入同一房间，成功拾取道具、在同一 JavaScript 任务内按下并松开 E 释放道具，以及掉线 AI 接管。
- 三赛道实测 3D 车头方向与左右横移一致；浏览器无未捕获异常。

仍未覆盖真实 iPhone／Android 的浏览器兼容性、触感、发热和长期帧率；不将本轮测试视为“绝对没有任何 bug”的保证。

## 2026-10-11 · 加速带接触与时长修复

- 加速带渲染与规则共用 4.7×8 米尺寸，判定包含车头、车尾、车身两侧及漂移姿态；使用整段移动轨迹检测，避免高速斜向擦过时漏判。
- 接触当帧更新加速状态，并立即提供最多 7 m/s 的速度增量（不突破加速极速上限）；松开油门也能持续加速，主动刹车仍优先。
- 持续时间由 1.7 秒延长至 **3.7 秒**，仪表显示剩余秒数。
- 同一次连续接触只触发一次，驶离后重新接触可以再次触发；已有更长的加速不被加速带或超级氮气缩短。
- 单人和服务端联机共用判定，双人接触各自独立；接触锁不进入网络快照。

验证：

- `npm run check` 通过；`npm test`：**56 项全部通过**。新增覆盖三赛道、三车型、车头／车尾／左右擦边、高速斜向穿过、未接触不误判、起终点接缝、松油门持续加速、精确时长、重复接触、长加速保护及双人快照。
- `test/boost-pad-browser.cjs` 在本机 Chrome 实际 WebGL 与游戏 UI 下通过，分别模拟低／高硬件配置，手机横屏 844×390。玩家在到达前松开油门，车中心位于加速带宽度之外，车身擦边后当帧显示 3.7 秒。低档采样速度由 178.0 升至 202.6 km/h，高档由 177.9 升至 202.5 km/h。浏览器无未捕获异常或 console warning。
- 截图：`artifacts/boost-pad-low-mobile.png`、`artifacts/boost-pad-high-mobile.png`。
- `git diff --check` 通过。设备提示模拟使用本机 GPU，不代表真实手机帧率测量。

## 2026-10-11 · 直线加速区与道具布局

- 三条闭环路线中加入 **320 米平直加速区**，通过平滑过渡与原有弯道相接；一圈实际长度约 1.62–1.68 公里。
- 直线上三个加速带沿中心车道布置，间隔七十米；末段留一百二十米直线供稳定车辆和准备入弯。其他两个加速带位于回程直线，避免弯道加速。
- 整个新直线及入口前八十米、出口后一百二十米内不摆道具箱、油污或路障；所有加速带前八十米、后一百二十米额外预留车身和障碍物长度余量，保持全车道无静态障碍。
- 其他路段的道具箱与静态障碍物至少间隔四十五米，障碍物之间至少间隔五十五米，保留横向绕行空间。
- 默认竞速与道具竞速均启用加速带；默认竞速仍不启用道具箱、油污或路障。接触加速和每次 3.7 秒时长沿用此前修复。
