## 2026-10-11 · 手动油门与独立车头朝向

- 默认关闭自动油门，玩家按住手机「油门」或键盘 W / ↑ 才起步。输入清洗仅接受显式 `throttle:true`，空输入不会隐式加速。

## 2026-10-17 · 车辆重量感、3D 场景与动力音效

本轮沿用 Three.js 0.186.1、原生 JavaScript、Web Audio、Node / WebSocket。驾驶、输入和赛道规则保持原有实现；没有新增运行时依赖。设计简报、核心循环和赛道表现计划见 `DESIGN.md`。

### 主要改动

- **车身与车轮分离表现**：阻尼弹簧根据纵向加速度、转向负载和路肩状态产生车身俯仰、侧倾与小幅起伏。加速抬头，刹车点头；车轮和接地阴影跟随道路。新增刹车盘 / 卡钳、车身接缝和尾部扩散器细节。每车独立的刹车灯材质，避免制动一辆车影响所有同车型。
- **镜头**：跟车保留车尾与前弯，速度和加速状态平滑改变视场；大角度侧滑时镜头横向位置限制在护栏内侧。引擎盖镜头朝向真实车头，避免沿赛道自动转向的观察错觉。静止无持续抖动，碰撞震动有衰减和幅度上限。
- **场景**：赛道使用独立于车库的户外反射环境，三主题分别调色；道路采用程序颗粒、粗糙度和微小凹凸，车漆 / 玻璃 / 金属分别调校。远山增加轮廓与明暗层次；夜赛建筑四侧显示窗口灯光，高清及以上开启一盏无阴影的车辆前灯照亮路面。
- **接地特效**：后轮接地点产生透明扩散烟雾、道路胎痕和短时碰撞火花。实例化面片与固定对象池复用；粒子仍遵守 18 / 36 / 64 / 96 的原画质预算，胎痕最多 192 段；碰撞火花可替换低优先级烟雾，满池时仍有清晰反馈。独立种子不改变比赛状态，重赛清理效果，减少动态效果偏好关闭额外胎烟 / 火花、碰撞震动、加速视场冲击和速度线。
- **动力合成**：V6 / V8 分别按每转 3 / 4 次点火脉冲形成基础音高，油门改变增益与谐波滤波；增加换挡卸载、涡轮松油门泄压，电驱使用独立双层电机音、静止时不发电机噪声。风噪、滚动、滑胎、路肩和加速声分层；近处最多两辆对手车按距离、左右位置和相对速度混音。引擎盖视角略增强发动机声，菜单 / 停止驾驶后淡出。

## 2026-10-17 · 3.0 手动竞速与完整比赛规则升级

### 原始现象与范围

用户反馈无操作仍一直沿道路中间跑。本机当前源代码的受控复现中，三赛道空输入 40 秒均停在起跑位置，单踩油门则第一弯撞停，未复现用户旧页面的全程居中；不能把该检查当作用户现象不存在。原有持久化自动油门入口、赛道相对运动表达、默认自动加速带、缺乏有效圈 / 检查点与撞停恢复，使玩法目标和操作因果都不清晰。本轮同时关闭旧设置、给出明确版本标识并完整升级驾驶 / 规则闭环。

### 交付行为

- 页面显示 **3.0 · 手动竞速**，入口 `/src/game.js?v=3`，服务 `/api/info` 返回 `version:3.0, driving:manual`。旧版自动油门配置与 `controls.autoThrottle=true` 都不能产生油门；默认两圈，不再呈现可开启的自动油门。
- `driving.js` 在独立世界坐标积分车头、纵向 / 侧向速度与角速度。道路投影只测量进度 / 横向偏移，不给人类车辆转向或吸回中心。抓地上限、路肩失速、制动 / 倒车和手刹滑移带来真实选择。
- 赛道竞速 / 时间挑战不生成或触发自动加速带、道具箱和危险物；道具竞速保留全部对应玩法。主动氮气仍要玩家按键；干净非起点检查点补 5 点，起点不送资源。

### 联调中确认并修复的问题

1. 旧 `vx` 是道路横向遥测，新物理读取 `sideSpeed/forwardSpeed`；车体、油污和路障的旧推挤没有进入物理。新增基于道路法线到车体分量的真实冲量接口，含非零车头方向的坐标转换。
2. 真实联机复测发现擦碰每帧固定加侧向速度，车辆已经分离仍不断被推，驾驶脚本错过第一个道具箱。负控实测：原先已经分离的赛车侧速会从 3m/s 增至约 5.8m/s。现在按相对接近速度 / 质量结算冲量，位置重叠纠正不继续注入能量；同一真实双客户端拾箱流程复测通过。
3. 早处理车手的脉冲命中晚处理车手时，后者的移动步骤会清掉当帧受击标记。将标记清理移到整帧开始，保证干净圈结果不依车手处理顺序。
4. 漏门后 R 已返回最后合法点，但漏门标志导致补足剩余门仍被迫多跑一圈。救车现在清除该失败尝试，保留已过检查点、脏圈与罚时，允许完成剩余门；未救车直接漏门仍不能计圈。
5. 原测试通过直接搬到终点准备冲线，这会绕过新检查点。迁移为先通过公开规则接口按受限速度赚取检查点，再测试最后一步实际过线；另保留“直接搬终点不能胜利”的负控。高速侧移 fixture 通过物理 `sideSpeed` 准备，停车 fixture 用 `park`，不把新倒车规则当作随机失败。

## 2026-10-17 · 3.1 制动预告、草地恢复与个人最佳幽灵

### 发现与修复

- **收紧弯被当成高速入口**：原 `cornerAdvice` 遇到首个超过阈值的曲率就返回。海岸 `s=995` 一处原提示约 166km/h，同方向更急位置的估算约 60km/h。现在扫描完整弯段和前方约 155～250 米，结合车型抓地与坡度，按当前速度估算制动距离；HUD 区分“约多少米后减速”“准备减速”“现在刹车”。路面箭头使用同一估算接口，提示不产生任何输入。该位置 40m/s 进弯时新提示约 70km/h，明确需要立即制动。
- **草地倒车近零振荡**：固定草地阻力 7m/s² 大于倒车驱动力 5m/s²，静止长按刹车会在零速两侧往复、反复切挡。实测10秒只倒退约 0.95 米，第一秒后出现154次挡位变化。草地阻力改为低速渐进，高速保持原阻力；三赛道回归均能稳定脱困，海岸同条件10秒倒退约 36.96 米，末速约 -4.27m/s，第一秒后挡位切换为0。松开后正常停住，不会自动前进或回中。
- **可追赶的个人最佳**：时间挑战中的完整干净、零罚时更快成绩保存本人实际轨迹；按赛道 / 圈数 / 车型 / 动力 / 难度隔离。最多10Hz、300秒、3002个样本及512000字符，保存模式与schema显式校验。坏记录、异常storage、缺少起终点、超过0.5秒采样缺口、不完整或脏成绩都不覆盖最佳；存储失败保留本次内存最佳，不影响比赛。
